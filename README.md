# California Housing K-Means Project

This project groups California census block groups by **region and median income** using the California Housing dataset. It follows an unsupervised-to-supervised machine-learning workflow:

1. Validate and prepare the dataset.
2. Split observations into reproducible training and test sets.
3. Fit a six-cluster K-Means model using `Latitude`, `Longitude`, and `MedInc`.
4. Assign cluster labels to all observations and visualize training/test predictions.
5. Train a supervised classifier to reproduce the K-Means labels.
6. Evaluate and save both models.

> The classifier learns labels generated by K-Means. Its metrics measure how well it reproduces those pseudo-labels, not human-verified geographic ground truth.

## Dataset

The supplied `housing.csv` contains the California Housing data from the 1990 California census. The modeling workflow intentionally uses only these three columns:

- `Latitude`
- `Longitude`
- `MedInc`

The script validates the required columns, reports data types, missing values, duplicate rows, and dataset dimensions before fitting models.

## Machine-learning workflow

### K-Means clustering

The clustering pipeline performs median imputation, standard scaling, and K-Means clustering with:

```python
KMeans(n_clusters=6, random_state=42, n_init=10)
```

The model is fitted only on the training set. The fitted pipeline predicts cluster assignments for the held-out test set. The resulting `cluster` column is saved in `data/processed/housing_clustered.csv`.

### Supervised classification

A majority-class `DummyClassifier` baseline is compared with a `RandomForestClassifier`. The workflow reports accuracy, macro precision, macro recall, macro F1-score, a classification report, and a confusion matrix.

## Setup and run instructions

Python 3.11 or newer is recommended. Run all commands from the repository root.

### 1. Create and activate a virtual environment (recommended)

Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

macOS/Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 2. Install dependencies

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

The workflow requires pandas, NumPy, scikit-learn, matplotlib, and joblib. These are included directly or through the project dependencies.

### 3. Confirm the input dataset

The runnable input must be available at:

```text
data/raw/housing.csv
```

The repository already includes the supplied California Housing dataset. The script also falls back to `.project_specs/housing.csv` if the normalized raw-data copy is missing.

### 4. Run the complete workflow

```bash
python src/app.py
```

The script will:

- Validate the dataset and required features.
- Split the data into 16,512 training rows and 4,128 test rows.
- Fit the six-cluster K-Means pipeline on the training set only.
- Assign and save cluster labels for all 20,640 rows.
- Generate the training/test cluster plot and the MedInc-by-cluster plot.
- Train and evaluate the Dummy baseline and Random Forest classifier.
- Generate the confusion matrix.
- Save and reload both model artifacts to verify predictions.

### 5. Inspect generated outputs

After a successful run, review:

```text
data/processed/housing_clustered.csv
models/kmeans_pipeline.joblib
models/cluster_classifier.joblib
reports/figures/kmeans_clusters.png
reports/figures/cluster_income_analysis.png
reports/figures/classifier_confusion_matrix.png
```

### 6. Open the exploratory notebook

Install Jupyter if it is not already available:

```bash
python -m pip install jupyter
```

Launch Jupyter from the repository root:

```bash
jupyter notebook src/explore.ipynb
```

Alternatively, open `src/explore.ipynb` in VS Code with the Python and Jupyter extensions installed. Run the notebook cells in order. The notebook shows Steps 1 through 5 with dataset checks, cluster counts, the three figures, classifier metrics, and model reload verification.

## Expected results

With the supplied dataset and `random_state=42`, a successful run produces:

- 20,640 processed rows with `cluster` and `split`
- Cluster IDs `0` through `5`
- 16,512 training rows and 4,128 test rows
- Dummy majority baseline accuracy near 0.33 and macro F1 near 0.08
- Random Forest accuracy near 0.996 and macro F1 near 0.994 when reproducing K-Means labels

Exact metrics can vary slightly with dependency versions. Clusters are distance partitions in standardized location-and-income space, not official California regions or exclusive income tiers.
